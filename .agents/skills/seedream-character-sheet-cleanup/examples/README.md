# Example Images

Place the two user-provided reference images for this skill in this folder.

Recommended filenames:
- `before_duplicate-face.png`
- `after_single-face.png`

These should represent:
- `before_duplicate-face.png`: the character sheet where the front full-body
  panel still shows a readable face in addition to the close-up panel
- `after_single-face.png`: the cleaned character sheet where only the close-up
  panel keeps the readable face

After the files are available locally, update `SKILL.md` to reference them as
the canonical before-and-after example pair.
