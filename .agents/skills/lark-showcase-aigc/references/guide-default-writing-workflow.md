## Default writing workflow

Unless the user specifies otherwise, follow this sequence:

1. Identify the target audience, use case, and desired business takeaway.
2. Gather the prompts, results, and any example structure the user wants to emulate.
3. If the showcase has 2+ approved scene videos, assemble the locked videos
   into one compilation highlight with `ffmpeg-scene-transitions` and verify it
   (see the "Highlight video compilation" subsection).
4. Normalize the material into external-facing language.
5. Create the Lark document structure.
6. Add the **Production Overview & Capabilities Matrix** and the **Highlight
   Video** (playable compilation or hero clip) near the top, right after the
   title — outcome first.
7. Add a concise executive summary and workflow overview.
8. Build the **input assets table** with reference images and their prompts as a column (Table-first layout, principle 1).
9. Build **audio assets table** (if applicable) as a single consolidated table with a Scene column (Table-first layout, principle 2).
10. Build one **scene-by-scene table** per scene with prompt + generated result side by side; consolidate into a single table when scenes share the same structure.
11. Add a conclusion section.
12. Fetch the final structure and verify no internal path or local-file wording remains.
