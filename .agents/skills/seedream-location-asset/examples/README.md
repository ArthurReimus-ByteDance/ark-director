# Example Images

This folder stores canonical example assets for the
`seedream-location-asset` skill.

Current example:
- `pirate-location.png`: pirate-era below-deck captain's cabin interior used as
  the canonical sample for the maritime location prompt in `../SKILL.md`

When updating the skill, keep the prompt in `SKILL.md` aligned with this image
so future agents can reuse the example consistently.
